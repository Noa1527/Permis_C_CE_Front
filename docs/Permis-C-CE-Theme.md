Choix validé par Mickaël le 17 octobre 2026. Appliquer ce thème par défaut à toutes les pages, composants, maquettes et propositions de code de ce projet, sauf demande explicite de modification.

## Règles visuelles

- Interface mobile-first, adaptée aux différentes tailles de téléphone.
- Fond clair pour les cours et les questions.
- Cartes arrondies, icônes simples, titres explicites et espaces généreux.
- Gros boutons faciles à toucher sur mobile.
- Police Arial ou Inter, texte lisible et aéré.
- Corrections avec icône et explication : ne pas transmettre le résultat uniquement par la couleur.
- Vérifier le contraste des textes ; privilégier du texte bleu nuit sur les boutons orange.
- Sélecteur Permis C / Permis CE bien visible.
- Rubriques : Écrit, Fiches orales, Vérifications, Examens blancs.
- Tableau de bord : progression et reprise des révisions.

## Implémentation

Frontend Angular et Tailwind. Réutiliser les mêmes couleurs et composants sur toute l’application. Le bleu nuit structure l’interface et l’orange identifie les actions principales.
